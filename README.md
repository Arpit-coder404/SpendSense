# SpendSense 💸
> **Same Money. More Freedom.**  
> *Spend smarter. Split easier. Live better.*

SpendSense is a student-first personal finance and expense management web application designed specifically for university and college students.

---

## 🎨 Design Philosophy: Two-World Design System

- **World 1 (Public Landing Page):** Warm cream (`#F5F0E5`), paper textures (`#FFFEFA`), handwritten notes (Caveat), lifestyle photography, yellow sticky notes (`#F3D66B`), hand-drawn arrows, and editorial typography.
- **World 2 (Personal Finance App):** Deep charcoal (`#111713`), dark forest-green (`#1C251F`), elevated surfaces (`#253129`), emerald financial indicators (`#38C98A`), mint (`#B8E6CB`), and tabular numerals for financial precision.

---

## 🚀 Key Features

1. **Dashboard:** Real-time financial overview with total spend, daily average, remaining budget, spending area chart, category doughnut, recent transactions, and quick action shortcuts.
2. **Transactions Journal:** Searchable spending notebook with type & category filtering, grouped date sections, custom add/edit/delete modal, and Indian currency formatting (`₹`).
3. **Budgets:** Category-based limits with warning alerts at 85% and 100% capacity.
4. **Split Bills:** Equal, custom amount, and percentage-based splitting among friends and roommates with settlement tracking.
5. **Groups:** Social expense management (Canteen Crew, Hostel Roomies, Goa Roadtrip) with outstanding balance computation between peers.
6. **Analytics:** Recharts spending trends, category breakdown, weekday vs. weekend spend comparisons, and rule-based insights.
7. **Snap & Track Receipt Scanner:** Camera/image upload with simulated scan animation and editable extracted fields before saving to transactions.
8. **Campus Money Pulse:** Anonymous, aggregated campus spending trends with editorial insights and privacy badges.
9. **Savings Goals:** Goal tracking with milestone celebration confetti, target dates, and contribution logs.
10. **Profile & Settings:** Custom campus/year, monthly budget limit, INR currency formatting, and one-click demo data reset.

## 🛠 Tech Stack

- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + Google Fonts (Space Grotesk, DM Sans, Caveat, Playfair Display)
- **Charts:** Recharts
- **Icons:** Lucide React
- **Date Handling:** date-fns
- **Effects:** canvas-confetti
- **State & Storage:** React Context + LocalStorage persistence
